# FlowCast Landing — Marketing Page

> The public-facing landing page for FlowCast.

---

## Live

[myflowcast.lovable.app](https://myflowcast.lovable.app)

---

## What It Is

Static marketing page for FlowCast — the AI-powered personal finance platform. Introduces the product, highlights key features, and directs users to the analytics app.

---

## Tech Stack

| Layer | Technologies |
|---|---|
| Framework | React, TypeScript |
| Build | Vite, Bun |
| Styling | Tailwind CSS |
| Hosting | Cloudflare Workers |
| Built with | Lovable |

---

## Getting Started

**Requirements: Node.js 18+ or Bun**

```bash
# 1. Clone the repo
git clone https://github.com/samettemurcin/flowcast-landing.git
cd flowcast-landing

# 2. Install dependencies
bun install

# 3. Start dev server
bun dev
```
